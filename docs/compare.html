Where Studio Bridge helps most

  • batch runs up to 50 edits as one undo step.
  • Tool groups keep your AI's tool list small: the 28 everyday tools cost about 5,700 tokens.
  • ui_responsive_check and the device emulator check a GUI on phones, tablets and consoles, and none of the 26 tools in Roblox's list does that.
  • Terrain, lighting, scatter, animation, audio and publishing tools.
  • Linux through Wine, and an optional Pro pack for snapshots and diffs.

Where WEPPY helps most

  • Two-way sync between Studio and local files, with a history (a Pro feature).
  • UI Studio for building in-game UI, a web dashboard, and a VS Code explorer extension.
  • Works with up to five open Studio windows.

If you want that sync workflow, it is built for it. Its terrain, bulk and animation tools sit behind its Pro license.

Where Roblox's built-in server helps most

  • Nothing to install: it is part of Studio.
  • Tools for generating meshes and materials, and explore and playtest subagents.
  • Maintained by Roblox and kept in step with the Assistant.
  • Connects to several open Studio windows at once, which Roblox calls experimental.

If its tools cover what you do, it is a fine place to start. You can run both side by side.

Other things worth knowing

  • Roblox's open-source studio-rust-mcp-server was archived on April 3, 2026, and its README recommends the built-in server.
  • kolvian/roblox-mcp-server, a fork of Roblox's Rust server, lists 9 tools and Windows and macOS downloads. It states no authentication.
  • boshyxd's README recommends the actively maintained fork Chrrxs/robloxstudio-mcp. Its README lists 24 tools by name, an MIT license and Linux through Wine. It is left out of the table to keep it readable.
  • Roblox's announcement and docs list the built-in server's tools.

Questions

Is Studio Bridge free?

Yes. All 79 tools are free, including for commercial games. Pro is an optional paid add-on with extra packs.

Does it work with my AI tool?

It speaks standard MCP, so any MCP-ready AI tool can use it. Claude Code is the one it is tested with, and studio-bridge install registers it for you.

Does it send my places anywhere?

No. The bridge listens only on 127.0.0.1 and collects no telemetry. Tools that reach Roblox, such as asset upload and publishing, run only when you ask your AI to use them.

Can I use it with the built-in Roblox server?

Yes, they are separate MCP servers, so you can connect both and let your AI use whichever tool suits the job.

How do I get it?

Follow the install guide. It takes two commands.
