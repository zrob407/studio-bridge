Let your AI work inside Roblox Studio

Studio Bridge is an MCP server and Studio plugin. It lets an AI coding assistant read and edit your place, run Luau, drive playtests, take screenshots and publish assets. 79 tools, free to use for commercial games.

Get started View on GitHub 
npm install -g @zrob407/studio-bridge
studio-bridge install

Why Studio Bridge

No forced restarts

Every command has a deadline and can be cancelled. Results survive a reconnect, and the plugin reloads itself when it changes.

Fewer calls and tokens

One batch call runs up to 50 edits as a single undo step. Tool groups keep the tool list small: the 28 everyday tools cost about 5,700 tokens.

Easy to trust

It listens only on 127.0.0.1, needs a secret on every request, verifies the plugin's signature, collects no telemetry and ships with build provenance.

Free for commercial games

Use it to make anything you like, including paid games. The core program stays free.

What you can ask for

"Generate a rocky island with a beach, scatter palm trees on it, and switch the lighting to sunset."

"Build a main menu, make it responsive, and check it on an iPhone, an iPad and an Xbox."

"Run a playtest, walk the character to the shop door, click Buy and tell me what errors show up."

"Find every script that uses DataStore and list the risky ones."

"List every asset this place uses that I do not own."

"Export every animation in this rig's AnimSaves folder and publish them to my group."

Studio Bridge Pro

Optional paid add-on packs on top of the free program. The first, Snapshots and diffs, saves part of a place, shows exactly what changed and rolls it back. More are planned. Nothing in the free program moves behind a paywall.

Works with

Claude Code

Used and tested here. studio-bridge install registers it for you.

Other MCP clients

Studio Bridge speaks standard MCP. Setup for OpenAI's Codex CLI is included but has not been tried with Codex itself.

Windows and Linux

Windows is the main platform. Linux works through Wine with Vinegar or Grapejuice, including Hyprland. Linux support is new, so reports are welcome.
