Get started

Install

You need Roblox Studio, Node 22 or newer and an MCP-ready AI tool such as Claude Code.

Windows

  1. Install the program

    npm install -g @zrob407/studio-bridge

    It runs on Node, which is signed by the OpenJS Foundation, so Windows protections such as Smart App Control do not block it the way they can block an unsigned exe.

  2. Set it up

    studio-bridge install

    This creates a secret token, writes the Studio plugin and registers Studio Bridge with Claude Code.

  3. Restart

    Restart your AI tool and Roblox Studio. If Studio asks, allow HTTP requests and Script Injection for "Studio Bridge".

  4. Check it

    studio-bridge doctor

    Doctor lists what is installed and tells you if something looks wrong. The Studio Bridge window in Studio should show Connected.

Prefer no Node? Download studio-bridge-<version>.exe from the releases page and double-click it. The exe is not code-signed, so Windows may warn about it. If it is blocked, use npm.

Linux

Roblox has no native Linux Studio, so this is for Studio running under Wine through Vinegar or Grapejuice. The bridge and your AI tool run natively on Linux, and Studio reaches the bridge on 127.0.0.1.

  1. Install and set up

    npm install -g @zrob407/studio-bridge
studio-bridge install

    The installer finds where Studio reads plugins, including Vinegar's app data folder and the Wine prefix.

  2. Start Studio from your launcher

    Allow HTTP requests and Script Injection for "Studio Bridge" if it asks, then run studio-bridge doctor.

The screenshot tool needs Windows, or Hyprland with grim. viewport_screenshot works everywhere. Input tools need Studio to be the focused window, which Studio Bridge arranges with hyprctl on Hyprland and xdotool on other X11 desktops. The packaged exe is Windows only, so use npm on Linux.

Keeping it up to date

studio-bridge update

Checking for updates is on by default and can be turned off in settings. New versions are announced on the releases page.

Help

Run studio-bridge doctor first. The README covers every setting, and you can open an issue on GitHub.
